# Uncategorized

A staging file, not part of the topic hierarchy — it carries no
`parent` and no `status`, and `scripts/wiki_lint.py` exempts it from the
structural checks.

Two jobs:

1. **Sources that have not clustered yet.** A source here is one that
   fits no existing topic and has no companions to form a new one. It
   stays visible in the lint's ORPHANED list, which is the real queue —
   this file just records *why* it is still waiting.
2. **Clusters awaiting your approval.** Topic pages are never created
   unilaterally (`AGENTS.md` rule 3), so proposals are parked here and
   survive between sessions instead of being lost when a session ends.

Re-read on every update: a source that did not cluster last time may
cluster with new arrivals.
