# Claude Code — entry point

The rules for this vault are in **[AGENTS.md](AGENTS.md)**. Read it
before touching anything. It is agent-agnostic on purpose, so every tool
working in this vault follows the same contract.

Summary of the parts that are easy to get wrong:

- `sources/` is **off-limits** — never create, edit or delete anything
  there, `_index.base` included. It is regenerated by the sync adapter.
- `topics/` is your workspace. **Integrate, never rewrite a whole page** —
  topic pages may be hand-edited, and that text is the most valuable in
  the vault.
- **New topic pages are proposed, not created unilaterally.**
- `python3 scripts/wiki_lint.py` is ground truth for what needs
  attention. Run it before and after any task touching `topics/`.
- Every claim carries a `[[citekey]]`. No exceptions.

Skills live in `.agents/skills/`. The copies under `.claude/skills/` are
pointers to them — edit the canonical ones.
