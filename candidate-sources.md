# Candidate sources

Papers found through external search that are **not in the library yet**.

This file is a shortlist for a human to review, nothing more. Adding
literature to the library is a human decision: an agent's job is to find
and de-duplicate candidates, never to enrol them. Nothing here is cited
by a topic page until it has been added to the library through your
reference manager and has appeared in `sources/`.

Workflow: an agent appends candidates here → you review → you add the
keepers to your reference manager → the sync adapter writes them into
`sources/` → they show up as orphaned in `wiki_lint.py` → the normal
update workflow folds them into topics.

See `.agents/skills/wiki-find-sources/SKILL.md`.
